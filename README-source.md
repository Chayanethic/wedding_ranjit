# সৃজিতা ♥ রঞ্জিত — 3 MP3 Wedding Website

## Add exactly these 3 MP3 files

Open the `assets` folder and replace the three `.PLACEHOLDER` files with your real MP3 files:

### 1. `01-bengali-wedding.mp3`
**Opening song:** old Bengali wedding song.

### 2. `02-sanai.mp3`
**Middle song:** Sanai / Shehnai wedding music.

### 3. `03-dj.mp3`
**Final song:** DJ / reception song.

Do not change the filenames.

## Music behavior

- Opening screen: `শুভ বিবাহ` + `সৃজিতা ♥ রঞ্জিত`
- Tap **Enter the Wedding** → Song 1 starts.
- Scroll into the story → Song 2 starts.
- Scroll into events/reception → Song 3 starts.
- Top-right Music button turns the soundtrack on/off.
- Browser autoplay restrictions are handled by starting audio from the Enter button.
